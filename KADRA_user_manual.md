# KADRA — руководство пользователя

Программа для кадрового учёта на одном компьютере.

Это руководство написано для человека, который садится за KADRA впервые. Оно проведёт вас по всему пути: от установки и настройки под свою организацию до выдачи справки, закрытия табеля и годового отчёта. Знать что-либо о компьютерах сверх умения открывать папки и файлы не нужно.

Читать подряд не обязательно. Если вам нужно одно конкретное действие — найдите его в оглавлении.

## 1. Что такое KADRA и что она делает

KADRA — это программа для кадрового делопроизводства небольшой организации: до нескольких тысяч человек в штате.

**Главное, что нужно понять с самого начала:** KADRA работает **только на вашем компьютере**. Она не отправляет данные в интернет, не хранит их «в облаке» и не требует подключения к сети для повседневной работы. Все сведения о сотрудниках лежат в одном файле на вашем диске. Это значит две вещи:

- никто посторонний не получит ваши кадровые данные через сеть;
- **если файл пропадёт, восстанавливать будет нечего, кроме как из вашей же резервной копии.** Раздел 16 — самый важный в этом руководстве.

Что KADRA умеет:

| Раздел | Для чего |
|---|---|
| Главная | Сводка: сколько сотрудников, фонд оплаты труда, дни рождения |
| Сотрудники | Картотека: карточки, поиск, импорт из Excel |
| Штатное расписание | Подразделения, должности, штатные единицы, вакансии |
| Движение кадров | Приёмы, переводы, увольнения с приказами |
| Табель | Учёт рабочего времени по форме Т-13 |
| Отсутствия | Отпуска, больничные, отгулы и их согласование |
| Календарь | Дни рождения, годовщины приёма, отсутствия на одном листе |
| Шаблоны справок | Конструктор бланков со вставкой данных сотрудника |
| Генератор документов | Печать и сохранение справок в PDF и Word |
| Отчёты | Пять готовых отчётов и конструктор своих |
| Архив | Данные прошлых периодов |
| Рекрутинг | Воронка найма, карточки кандидатов |
| Адаптация | Чек-листы приёма и увольнения |
| Оценка | Цели сотрудников и оценка 360° |
| База знаний | Внутренние статьи и инструкции |
| Настройки | Организация, валюта, копии, безопасность, лицензия |

## 2. Установка и первый запуск

### Установка

Вы получаете от продавца установочный файл KADRA. Запустите его и следуйте указаниям установщика. После установки KADRA появится в меню «Пуск» и, если вы согласились, ярлыком на рабочем столе.

### Первый запуск

Запустите KADRA. Произойдёт следующее:

1. Программа создаст себе базу данных — файл, в котором будет храниться всё.
2. В базу запишутся **демонстрационные данные**: несколько вымышленных сотрудников, подразделений и один шаблон справки. Они нужны, чтобы вы могли потрогать программу, не вводя ничего своего.
3. Откроется главный экран.

**Никакого входа по паролю и никакого создания учётной записи при первом запуске нет.** Программа открывается сразу. Это сделано намеренно: KADRA стоит на вашем личном рабочем компьютере, и запирать её от вас же при каждом включении незачем. Если пароль вам всё-таки нужен — раздел 6 объясняет, как его завести.

### Как убрать демонстрационные данные

Прежде чем вводить своё, уберите чужое — иначе вымышленные люди будут путаться с настоящими и портить все цифры в отчётах.

Самый быстрый способ:

1. Откройте **Настройки → Безопасность**.
2. Найдите блок «Сброс данных (опасная зона)».
3. Введите контрольное слово **УДАЛИТЬ** и, если вы уже задали пароль, пароль владельца.
4. Нажмите «Сбросить базу данных» и подтвердите.

Все данные будут удалены, и вы начнёте с чистого листа. Настройки оформления при этом сохраняются.

Способ помедленнее, зато выборочный: удалить демо-сотрудников по одному в разделе «Сотрудники», демо-подразделения и должности — в «Штатном расписании», демо-шаблон — в «Шаблонах справок».

> **Записи в разделе «Архив» так не удаляются.** Они создаются только при первом запуске и из интерфейса не чистятся. Полный сброс из «Безопасности» убирает и их.

## 3. Где хранятся ваши данные

Все ваши данные лежат в одном файле:

```
C:\Users\<ваше имя пользователя>\AppData\Roaming\com.kadra.local\local-hr-docs.db
```

Папку `AppData` Windows обычно прячет. Чтобы попасть в неё, нажмите `Win+R`, введите `%APPDATA%\com.kadra.local` и нажмите Enter.

Что полезно знать об этом файле:

- **Это и есть вся ваша кадровая база.** Скопировали файл — скопировали всё.
- **Копировать его можно только при закрытой программе.** Если скопировать на ходу, копия может оказаться испорченной.
- **Удалили файл — потеряли всё.** При следующем запуске KADRA создаст новый пустой файл и снова засеет демо-данные.
- Для штатного создания копий пользуйтесь разделом «Резервное копирование» (раздел 16) — это надёжнее ручного копирования.

## 4. Активация лицензии

KADRA — платная программа, и её нужно активировать на том компьютере, где вы работаете. До активации программа работает в режиме **«только чтение»**: смотреть можно всё, сохранять ничего нельзя.

Вы получаете от продавца **ключ лицензии** — строку вида `KDR-XXXXX-XXXXX-XXXXX-XXXXX`. Дальше возможны два пути, и какой именно ваш — зависит от того, что вам продали.

### Путь первый: активация через интернет

1. Откройте **Настройки → Лицензия**.
2. Введите ключ лицензии в поле на экране активации.
3. Нажмите кнопку активации.
4. Программа свяжется с сервером продавца и активируется сама.

Доступ в интернет нужен только в этот момент. Дальше программа работает без сети.

### Путь второй: активация файлами (без интернета)

Так активируют KADRA там, где интернета нет или он запрещён.

1. Откройте **Настройки → Лицензия**.
2. Введите ключ лицензии и нажмите создание запроса.
3. Программа предложит сохранить файл с расширением **`.kdrreq`**. Сохраните его, например, на рабочий стол.
4. **Передайте этот файл продавцу** — по почте, на флешке, как удобно.
5. Продавец пришлёт вам в ответ файл с расширением **`.kdrlic`**.
6. Вернитесь в **Настройки → Лицензия**, нажмите «Импортировать файл» и выберите присланный `.kdrlic`.

Готово. Лицензия активна.

> **Файл запроса привязан к вашему компьютеру.** Чужой файл лицензии не подойдёт, и ваш не подойдёт на другом компьютере — это не придирка, а защита от копирования.

### Что показывает экран лицензии

В **Настройки → Лицензия** всегда видно: состояние, владелец, номер лицензии, тариф, до какой даты оплачено, до какой версии KADRA действует лицензия и когда была последняя проверка.

Там же четыре действия: **проверить** (связаться с сервером и обновить состояние), **импортировать файл**, **создать файл запроса** и **деактивировать компьютер** (освободить место, чтобы перенести лицензию на другую машину).

## 5. Настройка под свою организацию

Это стоит сделать один раз в самом начале: данные отсюда подставляются в документы и влияют на то, как показываются суммы и даты.

### Настройки → Общие настройки

| Поле | Что это и на что влияет |
|---|---|
| Название организации | Подставляется в документы вместо переменной `{{Организация}}` |
| ИНН | Для реквизитов |
| ФИО руководителя | Для подписей в документах |
| Формат даты | Как даты выглядят по всей программе |
| Стартовый экран | Какой раздел открывается при запуске |

### Настройки → Общие → Денежные суммы

Здесь настраивается, как выглядят деньги по всей программе: символ валюты (манат, рубль, тенге — любой), стоит он перед суммой или после, сколько знаков после запятой и чем разделять тысячи. Внизу показан живой пример.

**Сделайте это до ввода окладов** — иначе будете смотреть на свои суммы с чужим значком.

### Настройки → Оформление

Цветовая тема (светлая, тёмная, как в системе), акцентный цвет, плотность интерфейса (насколько тесно расположены строки в таблицах) и размер шрифта. Если текст кажется мелким — здесь он увеличивается.

### Язык

Русский, английский, туркменский. Переключается в **Настройках** и в **Профиле**. Меняется сразу, перезапуск не нужен.

## 6. Учётная запись и пароль

**По умолчанию ни учётной записи, ни пароля нет, и программа открывается сразу.** Это нормальное рабочее состояние, а не «что-то не настроено».

Учётная запись нужна только если вам нужно одно из трёх:

- видеть своё имя в шапке программы;
- связать себя с собственной карточкой сотрудника (чтобы в «Отсутствиях» работала вкладка «Мои заявки», а в «Профиле» показывалась ваша карточка);
- поставить пароль на вход.

### Как завести учётную запись

1. Откройте раздел **Профиль** (нижний пункт бокового меню).
2. Справа найдите блок **«Учётная запись»**.
3. Заполните **Имя владельца** и, если хотите, **Email**. Достаточно чего-то одного.
4. Нажмите **«Завести учётную запись»**.

Там же имя и почту можно изменить в любой момент — просто поправьте и нажмите «Сохранить».

> **Имя важно писать так же, как в карточке сотрудника.** Связь между учётной записью и карточкой ищется по точному совпадению ФИО. «Иванов Иван Иванович» и «Иванов И.И.» — для программы разные люди.

### Как поставить пароль

Пароль можно поставить только после того, как появилась учётная запись.

1. **Настройки → Пароль**.
2. Введите новый пароль (не короче 6 символов) и повторите его.
3. Нажмите **«Сохранить пароль»**.

Поле «Текущий пароль» появится позже — оно нужно, только когда пароль уже есть.

### Как сменить пароль

Там же, в **Настройки → Пароль**: введите текущий пароль, затем дважды новый, и сохраните.

### Как убрать пароль

Там же кнопка **«Убрать пароль»**. Она спросит текущий пароль и подтверждение. После этого программа снова начнёт открываться сразу, а запрос пароля при входе выключится сам.

### Запрашивать пароль при входе

**Настройки → Безопасность → «Запрашивать пароль при входе»**.

Выключено — программа открывается сразу. Включите, если к компьютеру имеют доступ посторонние: тогда при каждом запуске будет спрашиваться пароль.

Тумблер недоступен, пока пароль не задан, — включить запрос несуществующего пароля значило бы запереть себя снаружи.

### Блокировка по бездействию

**Настройки → Безопасность → «Блокировка по бездействию»**.

Если вы отошли и не трогали программу заданное число минут, экран закроется и попросит пароль. Удобно, когда кабинет проходной.

Работает только при включённом запросе пароля при входе — снимать блокировку иначе было бы нечем.

> **Забытый пароль восстановить нельзя.** Единственный выход — восстановиться из резервной копии на чистой базе, потеряв всё, что введено после копии. Если пароль вам не нужен по-настоящему, не ставьте его.

## 7. Порядок работы: с чего начинать

Разделы KADRA связаны между собой, и вводить данные нужно в определённом порядке. Если нарушить его, счётчики и отчёты покажут ерунду — не потому, что сломались, а потому, что им не на что опереться.

**Правильный порядок:**

```
1. Подразделения          (Штатное расписание)
          ↓
2. Должности              (Штатное расписание, внутри подразделения)
          ↓
3. Сотрудники             (Сотрудники)
          ↓
4. Кадровые операции      (Движение кадров) — по мере работы
          ↓
5. Табель                 (Табель) — ежемесячно
          ↓
6. Документы и отчёты     (Шаблоны, Генератор, Отчёты) — по необходимости
```

Почему именно так: должность заводится внутри подразделения, поэтому подразделение должно существовать раньше. Сотрудник указывает своё подразделение и должность текстом, и счётчики занятости сверяют этот текст со справочником — значит, справочник должен быть готов заранее.

## 8. Шаг 1. Штатное расписание

Раздел **«Штатное расписание»** — это ваш справочник: какие есть подразделения и какие в них предусмотрены должности. Сотрудники сюда не вводятся, здесь только «скелет» организации.

### Как добавить подразделение

1. Нажмите **«Новое подразделение»**.
2. Введите название.
3. Выберите родительское подразделение — то, в которое оно входит. Для самого верхнего уровня (организации целиком) родителя не указывают.
4. Сохраните.

Подразделения показываются деревом: дочерние вложены в родительские, и ветку можно свернуть стрелочкой слева.

**Порядок ввода важен:** родитель должен быть заведён раньше ребёнка, иначе его не из чего будет выбрать.

Пример структуры:

```
ХО «Гарагум Техсервис»
├── Администрация
│   └── Бухгалтерия
├── Технический отдел
│   └── Сервисный участок
└── Отдел снабжения
```

### Как добавить должность

1. Слева в дереве **выберите подразделение**, в котором заводите должность.
2. Нажмите **«Новая должность»**.
3. Заполните:
   - **Название должности** — например, «Инженер-механик»;
   - **Количество ставок** — сколько таких единиц предусмотрено в штате;
   - **Оклад** — оклад по этой должности.
4. Сохраните.

### Сводка по штату

Наверху показываются три числа: **Штатных единиц**, **Занято**, **Вакантно**. Если в дереве выбрано подразделение — по нему, если ничего не выбрано — по всей организации.

**Как считается «Занято»:** программа берёт каждую должность из расписания и ищет сотрудников, у которых **название должности совпадает с названием должности в расписании посимвольно**, а подразделение — с подразделением этой должности. Уволенные не учитываются: они штатную единицу не занимают.

> **Это самое частое место, где новички получают «Занято: 0».** «Инженер-механик» и «Инженер–механик» (с длинным тире), «Бухгалтер» и «бухгалтер», «Отдел продаж» и «Отдел  продаж» (два пробела) — для программы это разные названия. Заводя сотрудника, **копируйте название должности и подразделения из справочника**, а не печатайте по памяти.

Сотрудник в отпуске штатную единицу **занимает** — это правильно, место за ним сохраняется.

## 9. Шаг 2. Сотрудники

Раздел **«Сотрудники»** — ваша картотека.

### Как завести сотрудника

Нажмите **«Добавить сотрудника»** и заполните карточку:

| Поле | Пояснение |
|---|---|
| ФИО | Обязательно, не короче 2 символов |
| Должность | Обязательно. Пишите точно как в штатном расписании |
| Подразделение | Обязательно. Пишите точно как в штатном расписании |
| Таб. номер | Табельный номер. Необязательно, но полезно |
| Статус | Работает / В отпуске / Испытательный срок / Уволен |
| Дата приёма | Обязательно |
| Дата рождения | Нужна для напоминаний о днях рождения |
| Форма оплаты | Оклад / Почасовая / Сдельная |
| Заработная плата | Сумма оклада |
| Ставка | 1 — полная, 0.5 — половина, 1.5 — полторы |

**Ставка** влияет на фонд оплаты труда: он считается как «оклад × ставка» по всем сотрудникам.

### Поиск, фильтры, сортировка

- **Поиск** вверху ищет сразу по всем полям: введите фамилию, должность или название отдела.
- **Фильтры**: по подразделению, по статусу, по ставке (полная, неполная, свыше ставки).
- **Сортировка**: щёлкните по заголовку колонки. Второй щелчок меняет направление.
- Кнопка сброса убирает все фильтры разом.

### Что можно сделать с сотрудником

Справа в каждой строке — кнопка с тремя точками. Под ней:

- **Изменить** — открыть и поправить карточку;
- **Сформировать док** — выбрать шаблон и сразу распечатать справку на этого человека;
- **История** — все кадровые операции по сотруднику: когда принят, куда переведён, что изменилось;
- **Удалить** — с подтверждением.

> **Не удаляйте уволенных.** Для увольнения есть кадровая операция (раздел 10): она ставит статус «Уволен» и сохраняет историю. Удаление стирает человека совсем, а на него могут ссылаться табели, архив и журнал движений.

### Импорт из Excel

Есть два способа.

**Быстрый** — кнопка «Импорт» прямо в разделе «Сотрудники». Подходит, если ваш файл уже озаглавлен так, как ждёт программа: колонки **ФИО, Должность, Подразделение, Статус, Дата приема, Таб. номер**. Чего нет — заполнится значениями по умолчанию.

**Мастер импорта** — **Настройки → Импорт / экспорт**. Подходит для любого файла. Четыре шага:

1. **Загрузка файла.** Поддерживаются Excel (`.xlsx`, `.xls`) и CSV.
2. **Сопоставление полей.** Программа покажет колонки вашего файла и предложит, какому полю карточки каждая соответствует. Догадки обычно верные, но проверьте. Ненужные колонки отметьте как «Не использовать».
3. **Проверка.** Строки с ошибками подсвечиваются и перечисляются с причиной: не заполнено обязательное поле, недопустимый статус, в числовом поле не число. **Такие строки не импортируются**, остальные — да.
4. **Импорт.** Программа сообщит, сколько сотрудников добавлено.

> Перед большим импортом **сделайте резервную копию** (раздел 16). Если результат не понравится, откатиться будет куда проще, чем удалять сотни строк руками.

### Экспорт

Кнопка «Экспорт» сохраняет текущий список в файл Excel.

## 10. Шаг 3. Движение кадров

Раздел **«Движение кадров»** — журнал приказов. Здесь проводятся три операции: **Приём**, **Перевод**, **Увольнение**.

Это не просто запись в журнал: **операция меняет карточку сотрудника**. В этом её смысл — вы проводите приказ один раз, и карточка обновляется сама.

### Что меняет каждая операция

| Операция | Что происходит с карточкой |
|---|---|
| **Приём** | Статус → «Работает». Дата приёма → дата операции. Плюс всё, что заполнено ниже: должность, подразделение, оклад |
| **Перевод** | Меняются только заполненные поля: новая должность, новое подразделение, новый оклад. Пустые поля карточку не трогают |
| **Увольнение** | Статус → «Уволен». Больше ничего не меняется |

**Карточка уволенного не удаляется.** На неё ссылаются история, табели и архив — удалить её значило бы испортить прошлые периоды.

### Как провести операцию

1. Нажмите нужную кнопку: «Приём», «Перевод» или «Увольнение».
2. Выберите сотрудника.
3. Укажите дату операции.
4. Впишите номер приказа, если он есть.
5. Для приёма и перевода — заполните новую должность, подразделение, оклад. Заполняйте только то, что меняется.
6. Укажите основание — например, «Заявление от 01.09.2026».
7. Нажмите **«Провести»**.

**Прежние значения программа подставит сама** — она берёт их из карточки на момент проведения. Вводить «было» руками не нужно, и ошибиться в этом нельзя.

### Журнал

В таблице видно: дата, тип операции, сотрудник, номер приказа, «было → стало» по должности и подразделению, старый и новый оклад, основание.

Фильтры: по типу операции и по диапазону дат. Кнопка экспорта выгружает **отфильтрованный** список в Excel — ровно то, что вы видите.

## 11. Шаг 4. Табель учёта рабочего времени

Раздел **«Табель»** — учёт рабочего времени по форме Т-13, помесячно.

### Как устроена таблица

Строки — сотрудники, колонки — дни месяца. Справа три колонки итогов: **Отработано**, **Явки**, **Часы**. Колонка с ФИО слева и итоги справа остаются на месте, когда вы прокручиваете дни.

Месяц переключается стрелками вверху. Можно отфильтровать по подразделению.

### Главное правило: незаполненные дни уже заполнены

**Пустая ячейка — не «ничего».** Программа считает её так:

- **выходной по календарю** (суббота, воскресенье) → код **В**;
- **любой другой день** → код **Я** (явка, 8 часов).

Поэтому открытый чистый табель сразу показывает полный месяц отработанных дней. Это сделано намеренно: обычный месяц обычного сотрудника именно такой, и отмечать вручную нужно только отклонения.

> **Из этого следует неочевидное:** первый щелчок по нетронутой ячейке рабочего дня выглядит так, будто ничего не произошло. На самом деле программа зафиксировала уже показанное значение «Я». Следующий щелчок сменит код.

### Как проставить код

Щёлкайте по ячейке — коды перебираются по кругу. Нужный код обычно в двух-трёх щелчках.

### Коды и сколько часов они дают

| Код | Что означает | Часов | Считается отработанным |
|---|---|---|---|
| **Я** | Явка | 8 | Да |
| **В** | Выходной | 0 | Нет |
| **ОТ** | Отпуск | 0 | Нет |
| **Б** | Больничный | 0 | Нет |
| **К** | Командировка | 8 | Да, но **не как явка** |
| **ОГ** | Отгул | 0 | Нет |
| **ВМ** | Вахта | 11 | Да |
| **МВ** | Межвахтовый отдых | 0 | Нет |
| **НН** | Неявка (причина не выяснена) | 0 | Нет |
| **ПР** | Прогул | 0 | Нет |

Буквенные коды — отраслевой стандарт формы Т-13, и они не переводятся на другие языки.

### Как читать итоги

- **Отработано** — дней, засчитанных как рабочие.
- **Явки** — из них те, когда человек был на рабочем месте. **Командировка входит в «Отработано», но не в «Явки»** — поэтому у командированного эти два числа различаются.
- **Часы** — сумма часов по кодам.

### Сохранение

Кнопка **«Сохранить»** записывает табель в базу. Пока вы не нажали её, проставленные коды живут только на экране.

> **Сохранение записывает табель всем сотрудникам** за этот месяц, а не только тем, кого вы правили, и не только видимым через фильтр. Это нормально: табель — документ на весь штат.

### Выгрузка

Кнопка **«Скачать»** сохраняет табель в Excel: дни по колонкам, итоги справа. Цифры в файле считаются тем же способом, что и на экране, — расхождений между тем, что вы видели, и тем, что выгрузилось, не бывает.

## 12. Шаг 5. Отпуска и отсутствия

Раздел **«Отсутствия»** — заявки на отпуск, больничный, отгул и удалённую работу.

### Как подать заявку

1. Нажмите **«Подать заявку»**.
2. Выберите сотрудника.
3. Выберите тип: Отпуск, Больничный, Отгул, Удалённая работа.
4. Укажите дату начала и дату окончания.
5. Отправьте.

**Количество дней считается само** по интервалу, включая обе граничные даты. Вводить его руками не нужно и нельзя — так в заявке не может оказаться число, не сходящееся с датами.

### Согласование

Новая заявка получает статус **«Ожидает»**. На вкладке **«Заявки команды»** у каждой есть кнопки **«Согласовать»** и **«Отклонить»**.

### Счётчики наверху

- **Доступно дней отпуска** — от годовой нормы в **24 дня** отнимаются уже согласованные отпускные дни за текущий год.
- **Ожидают согласования** — сколько заявок висит без решения.

Годовая норма сейчас зафиксирована в программе и в настройках не меняется.

### Вкладка «Мои заявки»

Показывает заявки того сотрудника, чьё ФИО совпадает с именем вашей учётной записи. Если учётной записи нет или имя не совпадает с карточкой — вкладка будет пустой. Это не ошибка; см. раздел 6.

### Важное ограничение

> **Согласованный отпуск не проставляется в табель автоматически.** Если сотрудник в отпуске с 7 по 11 сентября, вам нужно **отдельно** открыть «Табель» и проставить код **ОТ** на эти дни. Два раздела пока не связаны между собой.

Зато отсутствия **видны в «Календаре»** — там они показываются вместе с днями рождения и годовщинами.

## 13. Шаг 6. Шаблоны и документы

Выдача справки состоит из двух частей: один раз создать **шаблон** и потом сколько угодно раз **сформировать по нему документ** на разных людей.

### Шаблоны справок

Раздел **«Шаблоны справок»** — список ваших бланков. Кнопка **«Создать шаблон»** открывает конструктор.

Шаблон собирается из блоков:

- **Текст** — абзац документа. Основная часть;
- **Таблица** — таблица с показателями;
- **Подписи** — места для подписей сотрудника и руководителя.

В текст вставляются **переменные** — места, куда программа подставит данные. Переменная пишется в двойных фигурных скобках: `{{ФИО}}`.

### Какие переменные подставляются сами

| Переменная | Откуда берётся значение |
|---|---|
| `{{ФИО}}` | Из карточки выбранного сотрудника |
| `{{Должность}}` | Из карточки |
| `{{Отдел}}` или `{{Подразделение}}` | Из карточки |
| `{{Оклад}}` | Из карточки, в вашем формате валюты |
| `{{Дата приёма}}` или `{{Дата приема}}` | Из карточки |
| `{{Организация}}` | Из Настройки → Общие |

Можно писать и по-английски: `{{fullName}}`, `{{position}}`, `{{department}}`, `{{salary}}`, `{{hireDate}}`, `{{orgName}}` — это те же самые переменные.

**Любую другую переменную вы придумываете сами.** Напишете в шаблоне `{{ДатаВыдачи}}` или `{{СреднийЗаработок}}` — при формировании документа появится поле, куда это значение вводится руками.

Пример текста шаблона:

```
Настоящая справка выдана {{ФИО}}, занимающему(-ей) должность
{{Должность}} в подразделении {{Отдел}} организации {{Организация}}.

Справка выдана для предъявления по месту требования.
Дата выдачи: {{ДатаВыдачи}}
```

> **Переменная без значения остаётся в тексте как есть** — вы увидите в документе `{{ДатаВыдачи}}`. Это сделано нарочно: заметный маркер лучше, чем пустое место, которое уйдёт в печать незамеченным.

Сохранённый шаблон появляется в списке. Щелчок по карточке открывает его на правку, крестик удаляет.

### Генератор документов

Раздел **«Генератор документов»**:

1. Выберите **шаблон** слева.
2. Выберите **сотрудника** — его данные подставятся автоматически. Можно и без сотрудника, если справка не о человеке.
3. Заполните **поля переменных**, которых нет в карточке.
4. Смотрите предпросмотр справа — он обновляется сразу.
5. Нажмите:
   - **«Печать / PDF»** — откроется обычное окно печати Windows. В нём можно выбрать принтер или «Сохранить как PDF». В документ попадёт только сам бланк, без меню и кнопок программы, и всегда на белом фоне — даже если у вас тёмная тема.
   - **«Скачать .docx»** — сохранит документ в формате Word. Для этого в настройках должен быть указан путь к файлу фирменного бланка.

> Для переменных `{{Оклад}}`, `{{Дата приёма}}` и `{{Организация}}` поле ввода тоже появится. Оставьте его пустым — значение подставится из карточки и настроек само. Заполняйте, только если нужно подставить что-то другое.

Быстрый путь для одной справки: в разделе «Сотрудники» нажать три точки в строке человека → **«Сформировать док»** → выбрать шаблон → печать.

## 14. Шаг 7. Отчёты

Раздел **«Отчёты»** состоит из двух вкладок.

### Каталог: пять готовых отчётов

| Отчёт | Что показывает |
|---|---|
| **Списочная численность** | Все сотрудники: ФИО, должность, подразделение, дата приёма, статус |
| **Коэффициент текучести** | По месяцам выбранного года: сколько принято, сколько уволено, процент текучести. Считается по журналу движения кадров |
| **Табель учёта времени** | За выбранный месяц: отработано дней и сколько дней отсутствия. Цифры те же, что в разделе «Табель» |
| **Журнал кадровых движений** | Все приёмы, переводы и увольнения с приказами |
| **Штатная расстановка** | По каждой должности: штатных единиц, занято, вакантно, оклад. Цифры те же, что в «Штатном расписании» |

Выберите отчёт слева — он построится справа. Кнопка **«Скачать (Excel)»** выгружает ровно то, что показано на экране.

Для отчётов по табелю и текучести вверху выбирается период — год и месяц.

### Конструктор: свой отчёт

Если готовых не хватает, соберите свой:

1. **Источник** — откуда брать строки: Сотрудники, Штатное расписание, Табель, Архив, Кадровые движения, Кандидаты.
2. **Поля** — отметьте колонки, которые должны попасть в отчёт.
3. **Фильтр** — выберите поле и впишите значение. Можно оставить поле пустым: тогда искать будет по всем сразу.
4. **Группировка** — строки с одинаковым значением выбранного поля встанут рядом.
5. Готовый отчёт выгружается в Excel или JSON.

**Сохранённые наборы.** Настроив отчёт, дайте ему название и нажмите «Сохранить набор». В следующий раз он соберётся одним щелчком — удобно для того, что вы делаете каждый месяц.

## 15. Остальные разделы

### Главная

Четыре плитки и три блока сводки.

Плитки:

- **Сотрудники** — сколько всего в базе. Щелчок открывает картотеку;
- **Вакансии** — сколько штатных единиц не занято. Считается по штатному расписанию тем же способом, что и сводка в самом «Штатном расписании», куда плитка и ведёт по щелчку;
- **Шаблоны** — сколько шаблонов справок создано;
- **ФОТ** — фонд оплаты труда: сумма «оклад × ставка» по всем сотрудникам, в месяц. Сотрудник без оклада считается нулём — программа не придумывает за вас сумму.

Ниже:

- **Недавние события** — последние шесть записей журнала аудита: что произошло, с чем и когда. Полный журнал — в «Настройки → Журнал аудита»;
- **Дни рождения сегодня** — по датам рождения из карточек;
- **Сотрудники по отделам** — диаграмма по фактическому распределению.

### Календарь

Месячная сетка, на которой видно: **дни рождения**, **годовщины приёма** (с указанием, сколько лет человек работает) и **отсутствия** из раздела «Отсутствия». Справа — список ближайших событий.

### Архив

Данные прошлых периодов: год, месяц, сотрудник, подразделение, должность, оклад, отработанные часы. Фильтры по году, подразделению и сотруднику. Есть выгрузка в Excel и печать в PDF.

> **Архив из интерфейса не наполняется.** Записи в нём появляются только при первом запуске (демонстрационные) либо попадают туда при переносе данных. Отправить закрытый месяц из табеля в архив одной кнопкой пока нельзя.

### Рекрутинг

Воронка найма: доска с колонками **Новые → Скрининг → Собеседование → Оффер → Принят / Отказ**. Карточку кандидата перетаскивают мышью из колонки в колонку. Наверху — счётчики открытых вакансий, новых откликов и собеседований; есть поиск и фильтр по должности.

### Адаптация

Чек-листы для новых сотрудников («Новый сотрудник») и для увольняющихся («Увольняющийся»). Задачи отмечаются выполненными, к каждой можно оставить комментарий и указать ответственного. Показывается прогресс по каждому человеку.

### Оценка

Две вещи:

- **Цели (KPI/OKR)** — цель, процент выполнения, статус: «В процессе», «В зоне риска», «Выполнено».
- **Оценка 360°** — запускается на выбранный период по всей компании или по отдельным участникам. Коллеги ставят общую оценку от 1 до 5 и пишут отзыв.

### База знаний

Внутренние статьи: инструкции, регламенты, ответы на частые вопросы. Статьи разложены по категориям, есть поиск и счётчик просмотров. Редактор поддерживает полужирный, курсив, зачёркивание, заголовки, списки и цветной текст.

### Профиль

Ваша страница: учётная запись (раздел 6), связанная карточка сотрудника, если ФИО совпало, ваши отсутствия, задачи адаптации и кадровая история. Здесь же быстро переключаются язык и тема.

## 16. Резервные копии и сохранность данных

**Это самый важный раздел руководства.** Все ваши данные лежат на одном компьютере в одном файле. Сломался диск, украли ноутбук, случайно удалили — восстанавливать будет нечего, кроме как из копии, которую вы сделали заранее.

### Как создать копию

1. **Настройки → Резервное копирование**.
2. Нажмите **«Создать сейчас»**.
3. Программа сохранит файл вида `kadra-backup-2026-10-09-14-30-00.json` в папку загрузок.
4. **Перенесите этот файл в надёжное место:** на флешку, внешний диск, в сетевую папку. Копия, лежащая на том же диске, не спасёт от поломки диска.

Созданные копии перечисляются в таблице: файл, размер, дата создания, число записей.

> **Автоматических копий программа не делает — только то, что вы создали сами.** Об этом прямо сказано на самом экране, там же показана дата последней копии, а если ей больше недели, надпись становится предупреждающей.

**Создавайте копии регулярно:** раз в неделю, а перед любым массовым действием — импортом, очисткой модулей, сбросом — обязательно.

### Как восстановить из копии

1. **Настройки → Резервное копирование**.
2. Нажмите **«Восстановить из файла»** и выберите сохранённый `.json`.
3. Подтвердите.

> **Восстановление заменяет все текущие данные** данными из файла. Всё, что вы ввели после создания копии, будет потеряно. Программа переспросит, прежде чем это сделать.

### Что входит в копию

Все рабочие таблицы: сотрудники, подразделения, должности, шаблоны, табели, архив, кандидаты, заявки на отсутствия, задачи адаптации, цели, оценки, статьи базы знаний, кадровые движения.

**Учётная запись и пароль в копию не входят** — это сделано нарочно, чтобы файл копии не содержал ничего, чем можно войти в программу.

## 17. Журнал аудита

**Настройки → Журнал аудита** — летопись важных изменений: что, когда и кем было сделано.

Записываются: создание, изменение и удаление записей, проведение кадровых операций, вход в программу и неудачные попытки входа, смена пароля, создание резервных копий, очистка и сброс данных, изменение настроек.

Фильтры: по типу действия, по сущности и по дате. У каждой записи видны дата и время, пользователь, действие и краткое описание изменения. Действия и сущности названы по-человечески — «Добавление», «Кадровая операция», «Пароль изменён», — и так же попадают в выгрузку.

Журнал полезен, когда нужно понять, «кто это поменял и когда» — особенно если за компьютером работают несколько человек по очереди.

## 18. Очистка и сброс данных

**Настройки → Безопасность.** Здесь четыре действия, от самого безобидного к необратимому.

### 1. Сбросить оформление

Возвращает тему, акцентный цвет, плотность и размер шрифта к исходным. **Данных не касается.**

### 2. Сбросить все настройки

Возвращает к исходным все настройки: организацию, валюту, формат даты, стартовый экран. **Данных не касается.**

### 3. Очистить данные модулей

Выборочная очистка: отмечаете, какие модули чистить (например, только кандидатов и задачи адаптации), и нажимаете «Очистить выбранное». Остальные данные и все настройки остаются.

Если у вас задан пароль, потребуется ввести его.

### 4. Полный сброс к заводскому состоянию

Удаляет **все** данные. Чтобы случайно такое не нажать, нужно:

1. ввести контрольное слово **УДАЛИТЬ** в точности;
2. ввести пароль владельца, если он задан;
3. подтвердить, что резервная копия создана;
4. подтвердить ещё раз.

После сброса программа перезагрузится с чистой базой.

> Если пароль у вас не задан, пароль на этих действиях не спрашивается — сверять его не с чем. Защитой остаются подтверждения и контрольное слово. Это ещё одна причина поставить пароль, если к компьютеру имеют доступ посторонние.

## 19. Лицензия в повседневной работе

### Режим «только чтение»

Если лицензия не активирована, просрочена или отозвана, KADRA переходит в режим **«только чтение»**: вы видите все свои данные, можете их печатать и выгружать, но **сохранить ничего не получится**. При попытке что-то изменить появится сообщение об этом.

Данные при этом никуда не деваются и не портятся. Как только лицензия снова в порядке, работа продолжается с того же места.

### Продление подписки

Если у вас срочная лицензия (годовая, квартальная, месячная), после окончания оплаченного срока наступают **льготные дни** — программа ещё работает, но предупреждает. Когда и они заканчиваются, включается «только чтение».

Продление делается так же, как активация: онлайн — кнопкой «Проверить» в **Настройки → Лицензия**, офлайн — файлом от продавца.

### Перенос на другой компьютер

Лицензия привязана к конкретному компьютеру. Чтобы перенести её:

1. На **старом** компьютере: **Настройки → Лицензия → Деактивировать**. Место освободится.
2. На **новом**: установите KADRA и активируйте тем же ключом.
3. **Данные не переносятся сами.** Сделайте резервную копию на старом компьютере и восстановите её на новом (раздел 16).

Если старый компьютер уже недоступен — сломался, утерян, — обратитесь к продавцу: перенос без деактивации одобряется вручную.

### Переустановка Windows

Если на том же компьютере переустановили систему, KADRA может попросить **повторную привязку**. Создайте файл запроса и передайте продавцу — обычно это делается без лишних вопросов, компьютер тот же.

### Часы компьютера

Если перевести системные часы назад, KADRA это заметит и откажется работать, пока дата и время не будут исправлены. Это защита от обхода срока подписки, а не поломка.

## 20. Что делать, если…

| Ситуация | Что делать |
|---|---|
| **В «Штатном расписании» занято 0, хотя люди есть** | Названия должности и подразделения в карточке сотрудника не совпадают со справочником посимвольно. Проверьте пробелы, регистр, тире. Копируйте названия из справочника |
| **Сотрудник не находится поиском** | Проверьте, не включён ли фильтр по подразделению, статусу или ставке. Нажмите сброс фильтров |
| **В табеле у всех полный месяц, хотя я ничего не вводил** | Так и должно быть: незаполненные дни считаются явками, а выходные — выходными. Отмечайте только отклонения |
| **Щёлкнул по ячейке табеля — ничего не изменилось** | Первый щелчок закрепляет уже показанное значение. Щёлкните ещё раз |
| **Согласовал отпуск, а в табеле его нет** | Разделы не связаны. Проставьте код **ОТ** в табеле вручную |
| **Вкладка «Мои заявки» пустая** | Нет учётной записи или её имя не совпадает с ФИО в карточке сотрудника. См. раздел 6 |
| **В документе осталось `{{ДатаВыдачи}}`** | Переменная не заполнена. Впишите значение в поле слева от предпросмотра |
| **Не получается «Скачать .docx»** | Не указан путь к файлу фирменного бланка в настройках |
| **Ничего не сохраняется, появляется сообщение о лицензии** | Лицензия не активирована или просрочена. См. раздел 19 |
| **Забыл пароль** | Восстановить нельзя. Выход — восстановиться из резервной копии на чистой базе |
| **Программа просит пароль, а я его не ставил** | Проверьте, не включён ли чужими руками тумблер в «Настройки → Безопасность» |
| **Случайно удалил сотрудника** | Восстановите из резервной копии. Отмены удаления нет |
| **Случайно сделал полный сброс** | Восстановите из резервной копии |
| **Перенёс данные на новый компьютер, лицензия не работает** | Лицензия к данным не относится: её нужно деактивировать на старом компьютере и активировать на новом |

## 21. Чего KADRA пока не умеет

Честный список ограничений текущей версии, чтобы вы не искали несуществующее:

- **Нет автоматических резервных копий.** Копии создаются только вручную. Программа об этом честно предупреждает и показывает, когда копия делалась в последний раз, но сама её не создаёт.
- **Отпуск не попадает в табель автоматически.** Согласованное отсутствие нужно продублировать кодом в табеле.
- **Архив не наполняется из программы.** Закрытый месяц нельзя отправить в архив одной кнопкой.
- **Нет расчёта зарплаты.** KADRA ведёт кадровый учёт, а не бухгалтерию: она хранит оклады и считает фонд оплаты труда, но не начисляет и не удерживает.
- **Нет обмена с другими системами.** Ни выгрузки в бухгалтерские программы, ни загрузки из них — обмен идёт только через файлы Excel и JSON.
- **Нет многопользовательской работы.** Программа рассчитана на одного человека за одним компьютером. Несколько сотрудников одновременно с разных машин в одной базе работать не могут.
- **Нет восстановления пароля.** Забытый пароль означает потерю доступа к программе.
- **Годовая норма отпуска зафиксирована** на 24 днях и в настройках не меняется.
- **Демонстрационные данные** создаются при первом запуске, и их нужно убирать вручную.

## 22. Словарик

**База данных** — один файл на вашем компьютере, в котором хранится всё, что вы ввели.

**Резервная копия (бэкап)** — отдельный файл со снимком всех данных на определённый момент. Нужен, чтобы восстановиться, если с основным файлом что-то случится.

**Штатная единица** — одно рабочее место по штатному расписанию. Единиц может быть больше, чем людей: тогда есть вакансии.

**Вакансия** — незанятая штатная единица.

**Кадровая операция (движение)** — приём, перевод или увольнение, проведённое в программе. Меняет карточку сотрудника и остаётся в истории.

**Табель Т-13** — унифицированная форма учёта рабочего времени. Дни месяца по колонкам, буквенные коды в ячейках.

**Шаблон** — заготовка документа с переменными вместо данных конкретного человека.

**Переменная** — место в шаблоне вида `{{ФИО}}`, куда подставляются данные при формировании документа.

**Ставка** — доля полной занятости: 1 — полная, 0.5 — половина.

**ФОТ (фонд оплаты труда)** — сумма «оклад × ставка» по всем сотрудникам за месяц.

**Лицензия** — право пользоваться программой на конкретном компьютере. Без неё программа работает только на просмотр.

**Активация** — привязка лицензии к вашему компьютеру по ключу или через файл.

**Деактивация** — освобождение лицензии с этого компьютера, чтобы использовать её на другом.

**Режим «только чтение»** — состояние, в котором данные видно, но сохранять изменения нельзя.
